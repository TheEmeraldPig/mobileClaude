What each part does

Glasses

A tiny camera board on the frame. The button tells the hub to listen; when you ask something, the hub fetches a picture from the glasses so Claude sees what you're looking at. The light is on whenever a picture is taken.

Ears

The hub phone listens through its microphone (or your earbuds) until you stop talking, and turns your words into text with Android's speech recognition.

Claude

Claude Code runs in the Ubuntu inside Termux, logged into your own account. It stays running between questions so answers start quickly, and it uses your plan's usage, not a separate bill.

Voice

Android's text-to-speech reads the answer out one sentence at a time, while the rest is still being written.

The doctor

If the hub crashes five times in five minutes, Claude Code reads the log, fixes the hub's own code if it can, and restarts it. It keeps a fix only when the self-test passes; what it did shows up under Automatic repairs.
